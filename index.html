Tool index pane

A dashboard for the panes and apps in your Solid tool index: see what is registered, add a pane or an app, switch one off, remove one. The pane is one module, loaded by link.

Open a sample index

The SolidOS Browser asks before it adds a pane from a site it has not seen. Allow it, and the sample index opens as a list. The sample can be read but not changed; on your own pod the same screen saves what you do.

The pane: https://solid-panes.github.io/tool-index/tool-index-pane.js

Source and details: github.com/solid-panes/tool-index
